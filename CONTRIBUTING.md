# Contributing

Thanks for looking at Lumistar. It is intentionally small: a tray flyout with a handful of controls. Please keep changes in that spirit.

- Open an issue first for anything larger than a bug fix.
- Keep the code in English. Text shown to users goes into the `strs` table in `main.go`, one column per language.
- Build and test on Windows 10 or 11 before opening a pull request (see the README, "Build from source").
- Do not add background services, telemetry or new network calls.
