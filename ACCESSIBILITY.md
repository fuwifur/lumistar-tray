# Accessibility

## Supported environment

Lumistar runs on Windows 10 (version 22H2) and Windows 11.

## What is known

- The panel is drawn by the program itself (GDI+), not with standard Windows controls. Some screen readers may not announce its buttons and sliders.
- Keyboard-only use has not been tested.
- The interface text is available in 96 languages; the newest languages are partly in English on the help page.

## Reporting a barrier

If something in Lumistar is hard to use (for example a screen reader, keyboard, contrast, or text size problem), please open an issue on the project's GitHub page and describe the problem and your Windows version.
