# Code of Conduct

Lumistar is a small open-source project. Everyone who takes part in it (issues, pull requests, discussions, and any other space) is expected to be respectful and constructive.

## Expected behavior

- Be kind and patient, especially with people who are new to the project.
- Give and accept feedback on the work, not on the person.
- Keep discussions on topic.

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Publishing private information about someone without permission.
- Anything that would be inappropriate in a professional setting.

## Enforcement

The maintainer (fuwifur) may remove comments, close issues or pull requests, or block a person from the project's spaces if this code is broken. To report a problem, open a private security advisory on GitHub or contact the maintainer through the profile on GitHub.

This code is adapted from the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
